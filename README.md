# Helix Bio

面向生物医药资料研读、专业分析与文档制作的桌面工作平台。

## 下载与安装

**[下载 Windows 安装程序 · 0.3.17 · 约 1.29 GB](https://github.com/aiximi/helix-bio-releases/releases/download/v0.3.17/Helix-Bio-0.3.17-Windows-x64-Setup.exe)**

适用于标准 Windows 10 / 11，Intel 或 AMD 64 位电脑。建议预留至少 15 GB 可用磁盘空间。

1. 下载后双击安装程序，等待安装完成，应用会自动打开。
2. 打开“设置与连接”，填写自己可用的模型服务、模型名称和密钥，再检查连接。
3. 添加需要研读的资料，开始对话或专业工作。

首次工作空间为空。安装包不包含制作者的资料、聊天、项目或密钥，也不附赠模型服务额度；模型服务需要网络和对应账户权限。

## 随包能力

- 官方 Codex 执行引擎，20 个专业方法与 15 个工作场景。
- 图片、扫描件、PDF、音视频及 Word、PPT、Excel 的核心读取组件。
- Word、PPT、Excel 文档制作、来源关联、表格公式计算与文件预览。

核心组件与语音识别模型已内置，无需另装 Node.js、Python、Microsoft Office，或手动下载识别组件。资料库中的“移除”只解除收录，保留本地原件；卸载应用保留本机工作数据。
